  没有读取或解释神经网络输出。两个初始化上传、零中间 DtoH、一次最终
  DtoH API 调用，2,705,392 字节；不是物理 DMA 次数的测量。

## 环境修复记录

- 初始化 VS 2022，避免 Rust 自动选择缺少库的 VS 18 环境。
- Windows NVRTC 和 builtins 通过 CUDA_PATH 绝对路径预加载。
- NURBS kernel 的线程块从默认大块改为 64 线程，解决寄存器资源超限。
- Candle CUDA 构建设置 NVCC_CCBIN 和 `--use-local-env`，复用 VS 环境。
- 受限环境启动 Candle CUDA 可出现 STATUS_DLL_NOT_FOUND；正常本机会话
  将 CUDA 12.6 bin 加入 PATH 后运行成功，没有 CPU 自动回退。
- CAD wheel 下载中断后分段续传，核对 PyPI 官方 SHA-256：
  `3390be6d8199a50b01ae0137a60f56d0cfecd8753dbee08532bbbeb8b7169682`。
- SolidWorks 独立会话报告 COM 未注册（0x800401f3）。用户随后确认 STEP
  即可，因此未把本机 SolidWorks 导入验收作为完成条件。

## GPU harness 初版（2026-11-20）

3 组双候选检查故障注入、10 个主机输入拒绝案例。主批次覆盖 13 种结果，
