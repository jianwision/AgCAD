# 汽车曲面与多边形原语基线 v1

本文保留最初 46 项的范围和验收。当前库已扩展到 134 项；完整能力、
后端及限制见 [CAPABILITIES_V4.md](CAPABILITIES_V4.md)，当前验证见
[VALIDATION.md](VALIDATION.md)。

用户确认汽车曲面基线，并要求批量实现、包括多边形原语、集中测试。
这是一份有限且可验收的操作清单；不表示覆盖 CATIA 的所有命令。

## 验收清单

1. 曲线：直线、折线、圆/圆弧、椭圆、Bezier、NURBS、Catmull–Rom、参数裁剪。
2. 曲面：平面、Bezier patch、NURBS patch、直纹、拉伸、旋转、扫掠、截面放样、
   四边 Coons 填充、法向偏移、多边界填充。
3. 连续性：G1 连接带、G2 连接带、接缝 G0/G1/G2 检查、曲率/导数。
4. CAD 操作：曲线投影、曲面求交、UV 边界裁剪、面分割、曲线连接、面缝合。
5. 多边形：box、UV sphere、cylinder、cone、torus、grid、多边形三角化、
   面挤出、面内插、细分、焊点、法线、顶点截角。
6. 通用变换：平移、绕任意轴旋转、缩放、镜像。

共 46 个有独立验收条目的操作。每项在机器可读 catalog 中记录执行后端、
输入限制和测试结果；辅助函数不重复计数。

## 实现边界

- CUDA 提供曲线/曲面求值、控制网生成、连续性数学、变换和多边形算子。
- CAD 内核处理参数边界与稳健 B-rep 拓扑：投影、求交、分割、裁剪、
  多边界填充、连接和缝合。GPU 批量几何与 CPU 拓扑阶段明确分开。
- 扫掠包含 GPU 精确平移扫掠和 CAD 内核随路径扫掠；放样包含兼容截面
  的 GPU 插值及 CAD 内核拓扑构造。不会把任意变截面扫掠宣称为全 GPU。
- 多边形挤出/内插以单个平面简单多边形为输入；三角化支持凹多边形。
  顶点截角要求闭合凸流形，不冒充任意网格倒角。
- GPU offset 输出偏移定义/求值；STEP 可保留 offset surface 或由 CAD
  转换为样条。转换误差单独检查，不把采样点冒充精确控制网。
- 当前 769 参数模型保持四个 MVP 指令槽；新增库能力独立验收，尚未将
  所有新增操作加入模型训练头。

## 集中测试

- 一次批量 GPU 执行，曲线/曲面样本、控制网、网格和状态打包读回；
  算子之间不经过 CPU 解释。
- 独立解析或 CAD evaluator 参考；包含端点、内部、非单位权重和周期缝。
- 多边形检查索引、有限值、退化、方向、边界、流形性、Euler、面积/体积。
- 组合用例检查 G1/G2 接缝、裁剪后的边界、求交曲线的曲面残差、缝合后的
  闭合实体；STEP 重读比较有效性、实体/面数量和几何量。
- 所有条目必须有实际结果。失败项保留诊断，不通过减少测试或降低声明隐藏。
